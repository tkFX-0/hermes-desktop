# Shikishima Final Vision

`しきしま` is a local-first control-center plan for coordinating agents, models,
devices, and safety gates under human supervision.

## Vision

The system should eventually provide one calm operations room for:

- agent orchestration.
- safety review.
- model routing.
- redacted documentation.
- device display and expression.
- future controlled real operation.

## Non-Negotiable Baseline

- decision: HOLD until explicit review changes it.
- execution: disabled by default.
- productionReady: false.
- rawValuesReported: false.
- human approval required before any real execution boundary is crossed.

## Design Principles

1. Local-first.
2. Human-supervised.
3. Redacted by default.
4. Safety-gated.
5. Documentation before execution.
6. Static review before dynamic operation.

## Current Base

- RTX 4070 12GB PC is the primary development/runtime base.
- Mini PC remains deferred.
- Lenovo TAB6 is display-oriented.
- Redmi 12 is a prototype face/expression device.
- StackChan is future expression-only hardware and remains HOLD.
- iPhone 15 Pro remains private/read-only planning and review surface.

## Current Boundary

This document does not approve:

- WSL execution.
- Hermes execution.
- wrapper/dummy execution.
- RunPod startup.
- StackChan control.
- external network.
- installs.
- git push.
- GO transition.

この範囲では問題を検出していません。
