# Dedicated Device Plan

## Purpose

This plan records when a dedicated always-on device may be considered. It is a
future planning document only.

## Current Recommendation

- RTX 4070 12GB PC remains the main development and runtime base.
- Mini PC remains deferred / optional.
- A dedicated always-on node is not required for the current HOLD state.

## Consider a Dedicated Device Only If

- Phase 1-9 docs are approved.
- しずめ policy is approved.
- execution scope is explicit.
- rollback and shutdown procedures exist.
- private/local-only data handling is approved.
- the human explicitly approves the device role.

## Not Approved

- autonomous operation.
- unattended robot control.
- productionReady true.
- RunPod or cloud delegation by default.

この範囲では問題を検出していません。
