# Safe Progress Views

## Purpose

Safe Progress Views replace competitive rankings with non-competitive project
state groupings.

## Views

| View | Meaning |
|---|---|
| Ready for documentation review | docs can be reviewed by the human |
| Needs revision | docs need edits before approval |
| Blocked by execution gate | safe docs exist but execution is not approved |
| Draft only | early template or runbook draft |
| Approved for documentation | docs can be used as reference |
| Not approved for execution | execution remains disabled |

## Explicit Non-Goals

- No leaderboard.
- No earning.
- No reward mechanics.
- No autonomous task assignment.
- No marketplace.

この範囲では問題を検出していません。
