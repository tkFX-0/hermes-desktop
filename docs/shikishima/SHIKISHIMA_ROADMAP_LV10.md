## Lv9 — 制御された自律ループ

**体験:** 「放っておいても仕事してる。でも危ないことはしない」

### 実装内容

#### 9-A: 24時間サイクル定義
```
00:00-03:00 / 21:00-24:00: 夜間モード (低頻度チェック)
03:00-07:00: 夜の整理モード (しるべ日報・記憶整理 — `shikishima-goals.mjs` evening)
06:00-08:00: 朝の準備 (市場データ収集・はじめが計画立案)
08:00-09:00: 朝の報告 (はじめが今日の計画をDiscordに投稿)
09:00-21:00: アクティブモード (通常応答・リサーチ・タスク実行)
（夜の整理は 03:00–07:00 JST に移行 — 上記）
```

#### 9-B: 自律リサーチループ
```
しるべ + しきしまが自律的に:
  - FX/EA関連の最新情報を収集
  - 重要なものだけフィルタして報告
  - Obsidianに自動アーカイブ
```

#### 9-C: Human-in-the-Loop Gate
```
Lv5以上のアクション(ファイル書き込み・コード変更等)は
必ず「やっていいですか?」を確認してから実行
productionReady/execution フラグは人間GOなしで変えない
```

#### 9-D: 週次サイクル
```
毎週月曜朝:
  先週の積み残し確認
  今週のEAチャレンジ目標設定
  はじめが週間計画をDiscordに投稿
```

**StackChan統合準備:**
- StackChanの稼働スケジュールをしきしまの24hサイクルに同期するAPIを定義
