# Agent Tiny Symbols

## Purpose

Tiny symbols help identify each Shikishima agent without costumes, outlines,
large colored cards, or role-heavy badges.

Symbols must stay small enough that the face still feels like dots and lines
with whitespace.

## Symbol Table

| Agent | ASCII ID | Tiny symbol | Accent color | Use |
| --- | --- | --- | --- | --- |
| しきしま / しき | shikishima | center node / orbit dot | blue | coordination and conversation focus |
| しずめ | shizume | HOLD bar / gate line | blue-green | calm safety boundary |
| つむぎ / つむ | tsumugi | thread curve | amber/orange | making, weaving, patch drafting |
| はじめ | hajime | tiny arrow / first-step mark | green | route selection and next step |
| しるべ | shirube | bookmark / star-dot | violet | records, knowledge, handoff |

## Symbol Rules

- The symbol is optional.
- The symbol should be tiny and quiet.
- The symbol must not become a badge card.
- The symbol must not imply permission to execute.
- The symbol must not replace safety status.
- The symbol must not become a full logo system until separately reviewed.

## Accent Color Rules

Accent colors are small marks only. They should not fill the face, background,
or agent card.

Default face strokes remain black or near-black in the current preferred
direction.
