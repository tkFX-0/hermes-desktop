# Explorer-Style Dashboard Design

## Purpose

This document defines a static Explorer-style dashboard for the しきしま計画.
It uses high-level information architecture patterns only: visible protocol
state, agent directory, review queues, knowledge categories, tempo summaries,
and safe progress views.

## Adopted Ideas

- Protocol-style status display.
- Agent directory.
- Human review queue.
- Knowledge item index.
- Current development tempo.
- Safe progress groupings.
- Machine-readable status fields.

## Explicitly Not Adopted

- No wallet.
- No token system.
- No price or market section.
- No reward mechanics.
- No earning mechanics.
- No marketplace mechanics.
- No autonomous task execution.
- No external API.

## Static-Only Policy

- decision: HOLD
- execution: disabled
- productionReady: false
- rawValuesReported: false

The dashboard is a documentation view only. It does not approve execution, GO,
push, RunPod, StackChan, WSL, Hermes, wrapper, install, network, or production
readiness.

この範囲では問題を検出していません。
