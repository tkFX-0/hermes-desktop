Minimal Dot-Line Face System

Current preferred face direction

v0.6.0 supersedes the costume-heavy bust-up avatar direction for current face design. The preferred direction is face-parts only: no face outline, no torso, no costume, no full body, lots of whitespace, small black or near-black strokes, and tiny optional color accents.

This face design does not approve StackChan control or robot motion.

Mouth and eye animation concepts are design-only and not runtime implementation.

Design rules

  • no face outline
  • no torso
  • no costume
  • face-parts only
  • tiny symbols per agent
  • future mouth-flap design only
  • future gaze/blink design only
  • smartphone display-only
  • future StackChan display adaptation only
  • robot motion remains HOLD
