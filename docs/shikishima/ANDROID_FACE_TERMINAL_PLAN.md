# Android Face Terminal Plan

## Purpose

This draft describes a future Android face/expression terminal. It is not a
runtime implementation and does not approve camera, microphone, identity, or
robot control features.

v0.6.0 updates the preferred visual direction to a minimal dot-line face display:
face-parts only, no face outline, no torso, no costume, no full body, and large
whitespace.

## Candidate Devices

- Lenovo TAB6: read-only dashboard and display monitor.
- Redmi 12: prototype face/expression terminal.

## Allowed Future Direction

- static HTML/PWA expression display.
- smartphone display-only face surface.
- one active agent at a time.
- optional five-agent mini strip.
- tiny symbols and subtle accents.
- local-only expression state.
- no autonomous motion.
- no cloud upload by default.

## HOLD Items

- camera input.
- identity recognition.
- speech capture.
- robot control.
- networked control.
- microphone automation.
- camera upload.
- face recognition.
- autonomous expression control.
