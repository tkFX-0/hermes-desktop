# Android Face Terminal Plan

## Purpose

This draft describes a future Android face/expression terminal. It is not a
runtime implementation and does not approve camera, microphone, identity, or
robot control features.

## Candidate Devices

- Lenovo TAB6: read-only dashboard and display monitor.
- Redmi 12: prototype face/expression terminal.

## Allowed Future Direction

- static HTML/PWA expression display.
- local-only expression state.
- no autonomous motion.
- no cloud upload by default.

## HOLD Items

- camera input.
- identity recognition.
- speech capture.
- robot control.
- networked control.

この範囲では問題を検出していません。
